## 6.1 Mistake Categories

| Category | Description | Impact | Prevention |
|----------|-------------|--------|------------|
| Conceptual Errors | Genuinely did not know the concept | Loss of marks + knowledge gap | Revise topic thoroughly, practice more questions |
| Silly Mistakes | Knew the concept but answered incorrectly | Rank killer (10-15 marks = AIR 100 to 1000) | Track separately in error log, develop reading discipline |
| Calculation Errors | Arithmetic/algebraic mistakes in numericals | Avoidable mark loss | Write steps clearly, double-check, practice speed |
| Time Management Errors | Ran out of time, left questions unanswered | Potential marks lost | Mock practice with strict timing, skip strategy |
| Guessing Errors | Attempted without confidence | Negative marking penalty (~2.67 per wrong 2-mark Q) | Never guess randomly, only attempt if confident |
| Reading Errors | Misread the question | Complete mark loss | Read question twice before answering |
| Revision Errors | Forgot formula or concept | Lost easy marks | Daily RNP revision, maintain short notes |
