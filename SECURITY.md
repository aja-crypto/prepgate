# Security Policy

## Supported Versions

GateNexa is currently under active development. Security fixes are provided for the current production version.

| Version | Supported |
| ------- | --------- |
| Current production release | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in GateNexa, please report it privately rather than opening a public GitHub issue.

Use GitHub's **Private Vulnerability Reporting** feature to submit the vulnerability securely.

When reporting a vulnerability, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected feature, endpoint, or component
- The potential security impact
- Any proof-of-concept or relevant screenshots/logs, if available
- A suggested fix, if you have one

Please do not publicly disclose the vulnerability until it has been investigated and resolved.

### Response

We will review submitted reports and provide an initial response as soon as reasonably possible.

If the vulnerability is confirmed, we will work toward a fix and coordinate disclosure where appropriate.

If the report is determined not to be a security vulnerability, we will explain the reasoning where possible.

Thank you for helping keep GateNexa and its users secure.
